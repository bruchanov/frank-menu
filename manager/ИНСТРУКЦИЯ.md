# Таблица менеджера: настройка за 10 минут

Что получится: каждый стажёр открывает мини-апп, вводит имя и филиал, а его прогресс сам появляется в Google Таблице. Менеджер просто открывает таблицу.

## 1. Таблица и скрипт
1. Создай новую Google Таблицу, например «Frank · обучение».
2. Расширения → Apps Script. Удали всё, что там есть, и вставь содержимое файла `Code.gs`.
3. В первой строке поменяй `ПОМЕНЯЙ-МЕНЯ` на свой пароль (любое слово, лучше длинное). Запомни его.
4. Сохрани (значок дискеты). Выбери функцию `setup` в списке сверху и нажми «Выполнить». Разреши доступ к таблице (Google предупредит, что приложение не проверено: «Дополнительно» → «Перейти»). В таблице появятся листы «Стажёры», «История», «Сводка».

## 2. Публикация
1. В Apps Script: Развернуть → Новое развертывание → тип «Веб-приложение».
2. Выполнять от имени: **Меня**. Доступ: **Все**.
3. Нажми «Развернуть» и скопируй ссылку, она заканчивается на `/exec`.

## 3. Подключение приложения
Открой файл `config.js` в репозитории и впиши:

```js
window.FRANK_SYNC_URL = 'ссылка-на-/exec';
window.FRANK_SYNC_KEY = 'твой-пароль-из-Code.gs';
```

Сохрани и закоммить (Commit changes). Через минуту сайт обновится.

## 4. Проверка
Открой мини-апп → вкладка «Профиль», введи данные, ответь на пару карточек. Через 15 секунд (или сразу после кнопки «Отправить менеджеру сейчас» в «Настройках») в листе «Стажёры» появится строка.

## Как читать таблицу
- **Стажёры**: одна строка на человека. Красным подсвечены те, кто не заходил больше 3 дней.
- **История**: активность по дням.
- **Сводка**: средние показатели по филиалам.

## Важно знать
- Это пилотная защита: пароль лежит в `config.js`, его может увидеть тот, кто откроет код сайта. Для пилота на один-два филиала этого достаточно, для всей сети нужен вход по аккаунтам.
- В таблице хранятся имя, фамилия и Telegram. Для настоящего внедрения согласуй хранение персональных данных с руководством.
- Если поменяешь код скрипта, нужно заново: Развернуть → Управление развертываниями → Изменить → Новая версия.
